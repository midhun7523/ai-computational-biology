## Suggested learning order

1. Python basics and Git/GitHub.
2. Tables, data cleaning and plotting.
3. Statistics and linear algebra foundations.
4. Core molecular biology and genetics.
5. Sequence databases and introductory bioinformatics.
6. Machine learning fundamentals and evaluation.
7. A small public-data project with a clear biological question.

You do not need to learn every tool at once. Build foundations, practise regularly, and make each project reproducible.
