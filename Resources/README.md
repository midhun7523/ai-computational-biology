# Resources Folder

Use this folder for original, student-created learning aids that are safe to redistribute.

Suggested additions:
- `glossary.md` — plain-language definitions of AI, ML, genomics, transcriptomics, proteomics and bioinformatics.
- `ai_cb_concept_map.png` — an original diagram connecting biology, mathematics, statistics, programming and AI.
- `project-template/` — a reusable project README and notebook template.
- `papers-to-read.md` — short summaries and links to papers, with correct citations.

Do not upload copyrighted textbooks, paid course materials, private student information, confidential research data or datasets whose licence does not permit redistribution. Link to the original source when possible.
